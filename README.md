# 🎮 Guess The Number
A simple number guessing game built using HTML, CSS, and JavaScript.

## 🚀 Features
- Guess number between 1 to 50
- Too high / Too low hints
- Correct answer message
- Interactive UI

## 🛠 Technologies
- HTML
- CSS
- JavaScript

## 📚 Concepts Used
- DOM Manipulation
- Event Handling
- if-else Conditions
- User Input

👨‍💻 Built for JavaScript practice
